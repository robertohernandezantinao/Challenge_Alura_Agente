# Primeros Pasos

**Producto:** Nexa Knowledge AI

**Empresa:** NexaDigital S.A.S.

**Versión del documento:** 1.0

**Estado:** Vigente

**Clasificación:** Público

---

# 1. Introducción

## Objetivo

El presente documento describe el proceso inicial para comenzar a utilizar Nexa Knowledge AI.

Su finalidad es guiar al usuario desde el primer acceso a la plataforma hasta la realización de su primera consulta mediante Inteligencia Artificial, proporcionando una visión general de la interfaz y de las operaciones básicas disponibles.

---

# 2. Requisitos Previos

Antes de utilizar la plataforma, el usuario deberá disponer de:

- Una cuenta de usuario activa.
- Credenciales de acceso válidas.
- Permisos asignados por un administrador.
- Acceso a una organización.
- Acceso a un Workspace autorizado.
- Conexión estable a Internet.
- Un navegador web compatible.

Sin estos requisitos no será posible utilizar la plataforma.

---

# 3. Acceso a la Plataforma

El acceso a Nexa Knowledge AI se realiza mediante la dirección proporcionada por la organización.

Proceso general:

1. Abrir el navegador web.
2. Acceder a la URL oficial de la plataforma.
3. Introducir las credenciales de acceso.
4. Completar la autenticación requerida.
5. Ingresar al sistema.

Si la organización utiliza autenticación centralizada (SSO), el proceso podrá variar según la configuración establecida.

---

# 4. Inicio de Sesión

Para autenticarse correctamente, el usuario deberá proporcionar:

- Correo electrónico o nombre de usuario.
- Contraseña.
- Segundo factor de autenticación (cuando esté habilitado).

Una vez validada la identidad, la plataforma mostrará el entorno correspondiente a los permisos del usuario.

---

# 5. Primer Ingreso

Durante el primer acceso, la plataforma podrá solicitar algunas configuraciones iniciales, como:

- Aceptación de los Términos de Uso.
- Confirmación de la Política de Privacidad.
- Cambio de contraseña inicial (cuando aplique).
- Configuración del perfil.
- Verificación del correo electrónico.

Estas acciones solo deberán realizarse una vez.

---

# 6. Selección de Organización

Si el usuario pertenece a más de una organización, deberá seleccionar aquella con la que desea trabajar.

La organización determina:

- Los documentos disponibles.
- Los usuarios asociados.
- Los permisos asignados.
- Los Workspaces accesibles.
- Las configuraciones específicas.

Una vez seleccionada, el usuario podrá comenzar a utilizar la plataforma.

---

# 7. Selección del Workspace

Después de ingresar a la organización, el usuario deberá seleccionar un Workspace autorizado.

Cada Workspace representa un espacio de trabajo independiente que contiene:

- Documentación.
- Conversaciones.
- Configuración.
- Recursos asociados.

El contenido visible dependerá de los permisos del usuario.

---

# 8. Conociendo la Interfaz

La interfaz de Nexa Knowledge AI está diseñada para facilitar el acceso rápido a la información.

Generalmente incluye los siguientes elementos:

- Barra superior.
- Menú lateral.
- Área principal de trabajo.
- Chat IA.
- Historial de conversaciones.
- Gestión de documentos.
- Perfil del usuario.
- Configuración.

La disponibilidad de cada opción dependerá del rol asignado.

---

# 9. Navegación Básica

El usuario puede desplazarse entre las diferentes funcionalidades mediante el menú principal.

Las opciones más habituales son:

- Inicio.
- Chat IA.
- Documentos.
- Workspaces.
- Usuarios (según permisos).
- Administración (según permisos).
- Configuración.

La navegación está diseñada para mantener una experiencia consistente en toda la plataforma.

---

# 10. Realizar la Primera Consulta

Para realizar una consulta:

1. Acceder al Chat IA.
2. Escribir una pregunta en lenguaje natural.
3. Enviar la consulta.
4. Esperar el procesamiento.
5. Revisar la respuesta generada.

Ejemplo:

> ¿Cuál es la política de vacaciones de la empresa?

El Agente IA analizará la documentación disponible y generará una respuesta basada en la información autorizada.

---

# 11. Interpretación de las Respuestas

Las respuestas generadas por el Agente IA se basan en la documentación disponible dentro de la base de conocimiento.

El usuario deberá:

- Leer cuidadosamente la respuesta.
- Revisar la información proporcionada.
- Validar el contexto cuando sea necesario.
- Formular preguntas adicionales si requiere mayor detalle.

Cuando la documentación no contenga información suficiente, el Agente IA podrá indicar que no dispone de datos para responder con precisión.

---

# 12. Buenas Prácticas Durante el Primer Uso

Se recomienda:

- Formular preguntas claras.
- Utilizar lenguaje natural.
- Realizar una consulta por tema.
- Revisar las respuestas antes de tomar decisiones.
- Familiarizarse con la estructura del Workspace.
- Explorar la documentación disponible.

Estas prácticas mejoran la calidad de las respuestas obtenidas.

---

# 13. Seguridad Durante el Uso

Todo usuario deberá:

- Mantener la confidencialidad de sus credenciales.
- Cerrar sesión al finalizar su trabajo.
- No compartir información sensible con personas no autorizadas.
- Utilizar únicamente dispositivos confiables.
- Reportar accesos sospechosos.

El cumplimiento de estas medidas contribuye a proteger la información de la organización.

---

# 14. Cierre de Sesión

Al finalizar la jornada de trabajo, el usuario deberá cerrar correctamente su sesión.

Proceso general:

1. Acceder al menú del perfil.
2. Seleccionar la opción **Cerrar sesión**.
3. Confirmar la acción, si corresponde.

Esta práctica reduce el riesgo de accesos no autorizados.

---

# 15. Problemas Frecuentes Durante el Primer Acceso

Algunas situaciones habituales son:

| Situación | Acción recomendada |
|-----------|--------------------|
| No puedo iniciar sesión | Verificar las credenciales y contactar al administrador si el problema persiste. |
| No aparecen documentos | Confirmar que el usuario tenga acceso al Workspace correspondiente. |
| No puedo realizar consultas | Verificar que exista documentación indexada y que el usuario disponga de permisos suficientes. |
| No encuentro una opción del menú | Confirmar que el rol asignado permita acceder a dicha funcionalidad. |
| El sistema responde con un error | Registrar el mensaje mostrado y reportarlo al equipo de soporte. |
