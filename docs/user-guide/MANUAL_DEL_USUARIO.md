# 1. Introducción

## Objetivo

Este manual proporciona una guía completa para que cualquier usuario pueda utilizar Nexa Knowledge AI de forma eficiente y segura.

Describe el funcionamiento general de la plataforma, las principales funcionalidades disponibles y las buenas prácticas recomendadas para consultar información mediante Inteligencia Artificial.

Este documento constituye la referencia principal para los usuarios finales de la plataforma.

---

# 2. ¿Qué es Nexa Knowledge AI?

Nexa Knowledge AI es una plataforma SaaS que permite consultar la documentación interna de una organización utilizando lenguaje natural.

En lugar de buscar manualmente entre cientos de archivos, el usuario puede realizar preguntas directamente al Agente IA y recibir respuestas fundamentadas en la Base de Conocimiento de la empresa.

---

# 3. ¿Qué puede hacer la plataforma?

Con Nexa Knowledge AI es posible:

- Consultar documentos mediante lenguaje natural.
- Buscar información sin conocer el nombre del archivo.
- Obtener respuestas respaldadas por fuentes documentales.
- Conversar con Agentes IA especializados.
- Acceder únicamente a la información autorizada según el rol del usuario.
- Organizar documentos por Workspaces y Colecciones.
- Consultar el historial de conversaciones.
- Compartir conversaciones cuando la organización lo permita.

---

# 4. Flujo general de uso

El uso habitual de la plataforma sigue el siguiente flujo:

1. Iniciar sesión.
2. Seleccionar un Workspace.
3. Elegir un Agente IA.
4. Escribir una consulta.
5. Revisar la respuesta.
6. Consultar las fuentes utilizadas.
7. Continuar la conversación o iniciar una nueva.

---

# 5. Conceptos básicos

Antes de utilizar la plataforma es recomendable comprender los siguientes conceptos.

## Organización

Empresa que utiliza Nexa Knowledge AI.

---

## Workspace

Espacio donde se agrupan documentos y recursos relacionados con un área o proyecto.

Ejemplos:

- Recursos Humanos
- Ingeniería
- Comercial
- Finanzas

---

## Colección

Conjunto de documentos relacionados.

Ejemplos:

- Manuales
- Procedimientos
- Políticas
- Contratos

---

## Documento

Archivo que forma parte de la Base de Conocimiento.

---

## Agente IA

Asistente inteligente especializado en responder preguntas utilizando únicamente información autorizada.

---

## Conversación

Historial de preguntas y respuestas entre un usuario y un Agente IA.

---

- Configuración del usuario.

---

# 7. Ciclo de una consulta

Cuando un usuario realiza una pregunta ocurre el siguiente proceso:

1. El sistema valida la autenticación.
2. Verifica los permisos del usuario.
3. Interpreta la consulta.
4. Recupera documentos relevantes.
5. Construye el contexto.
6. Consulta el modelo de lenguaje.
7. Genera la respuesta.
8. Presenta las fuentes utilizadas.

Todo este proceso ocurre automáticamente.

---

# 8. Buenas prácticas

Para obtener respuestas de mayor calidad se recomienda:

- Formular preguntas específicas.
- Utilizar nombres reales de procesos o documentos cuando se conozcan.
- Realizar una pregunta por consulta.
- Evitar preguntas excesivamente generales.
- Revisar las fuentes citadas por el Agente IA.
- Continuar la conversación cuando las preguntas estén relacionadas.

---

# 9. Ejemplos de consultas

## Recursos Humanos

- ¿Cuál es la política de vacaciones?
- ¿Cómo solicito una licencia médica?
- ¿Cuántos días de permiso administrativo existen?

---

## Ingeniería

- ¿Cómo se despliega una nueva versión?
- ¿Cuál es el procedimiento de Code Review?
- ¿Qué ramas utiliza GitFlow?

---

## Comercial

- ¿Qué incluye el Plan Enterprise?
- ¿Cuál es el SLA para clientes Premium?
- ¿Cómo se genera una cotización?

---

## Finanzas

- ¿Cuál es el procedimiento para aprobar gastos?
- ¿Cómo se solicita un reembolso?

---

# 10. Recomendaciones de uso

El Agente IA responderá mejor cuando:

- La documentación esté actualizada.
- Los documentos estén correctamente organizados.
- Las colecciones sean coherentes.
- Los permisos estén correctamente configurados.

---

# 11. Seguridad

Por motivos de seguridad:

- Nunca comparta sus credenciales.
- Cierre la sesión al finalizar.
- Respete las políticas internas de la organización.
- No solicite acceso a información para la cual no esté autorizado.

---

# 12. Soporte

Si encuentra problemas durante el uso de la plataforma:

1. Revise la documentación disponible.
2. Consulte las Preguntas Frecuentes (FAQ).
3. Contacte al administrador de su organización.
4. Si el problema persiste, comuníquese con el equipo de soporte de NexaDigital S.A.S.
